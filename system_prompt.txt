次の JSON 配列について、"original" を日本語に翻訳し、"translation" に結果を書き込んで返してください。

🚫 絶対禁止
・余計な文章の追加
・key の変更
・original の変更
・キーの順番を変えること
・タグの削除・変更（例: #t, #!, #i, #b など）

🎯 翻訳ポリシー
・説明文ゲーム調だが必要に応じて自然な日本語ゲーム文調にしてよい
・句読点は「、。」を使う
・全角を優先
・アイテム名・地名は原語維持
・固有名詞だと判断できる語は極力翻訳しない
・口語にしない（敬体・常体は original の文脈に合わせる）

📌 返す形式
JSON配列のみ。
各要素は以下のような形：
{ "key": "...", "original": "...", "translation": "翻訳文", "stage": x }

translation が空白または存在しない要素のみ翻訳し、
すでに translation がある要素はそのまま返す。

⚠️ JSON配列以外の文章（説明・注釈・コメント）を一切含めないこと。
